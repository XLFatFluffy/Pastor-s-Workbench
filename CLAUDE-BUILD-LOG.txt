## v0.6.4 — KJV Download Repair (2026-08-19)
- Investigated the reported `Download stopped: No KJV data returned for Genesis.` failure.
- Confirmed the configured HolyBooks Genesis endpoint is valid and returns the expected `text`/chapter structure.

- Preserved the existing HolyBooks source and canonical normalization logic.
- Full test suite: 22 passed, 0 failed, 0 skipped.

2026-08-20 v0.12.8 — DESKTOP DATA FOLDER FIX (critical)
---------------------------------------------------------
Root cause found: prepare-desktop.mjs (the script that assembles the isolated
`frontend/` directory Tauri actually bundles) copied index.html, styles.css,
main.js, every root-level service file, and views/ — but never copied data/.
confessionService.js imports data/1689/seed.json, chapters.json, and
verification.json directly as ES module JSON imports, and
crossReferenceService.js fetches data/crossrefs/seed.json at runtime. Since
data/ never reached the built frontend, the 1689 Confession module import
would fail outright in the desktop build and Cross References would fail its
fetch — while browser/dev mode (which runs from the project root, where
data/ still sits alongside everything else) worked fine. This explains
desktop-only breakage that wasn't reproducible when just opening the files
in a browser.
Fix: added 'data' to the `dirs` list in prepare-desktop.mjs alongside
'views', so `data/1689`, `data/bible`, and `data/crossrefs` are now copied
into frontend/ on every desktop:build / desktop:dev run. Verified by running
prepare-desktop.mjs and confirming confessionService.js resolves its JSON
imports from the built frontend/ directory without error.
Also cleaned two harmless but confusing stray files from the zip: a 0-byte
file literally named "BUILD PASTORS" (a truncated leftover, not the real
"BUILD PASTORS WORKBENCH DESKTOP.bat", which is intact) and an empty
views/settingsView.js.tmp editor leftover. Neither was referenced by any
code, so removing them changes nothing functionally.
Full syntax check (node --check on every .js/.mjs file) and full test suite
(55/55 passing) re-verified after the fix. Version bumped to 0.12.8 in
VERSION.txt, package.json, tauri.conf.json, Cargo.toml, and the Settings
"Installed version" display.

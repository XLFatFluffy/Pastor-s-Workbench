## v0.6.4 — KJV Download Repair (2026-08-19)
- Investigated the reported `Download stopped: No KJV data returned for Genesis.` failure.
- Confirmed the configured HolyBooks Genesis endpoint is valid and returns the expected `text`/chapter structure.
- Root cause: an older/broken KJV record in IndexedDB could be returned by `getLocalBook()` even when its `data` object had no usable `chapters` array. The downloader then treated that stale record as the remote result and stopped with the misleading error.
- Changed local Bible loading to validate that a cached book contains a non-empty `chapters` array. Invalid/stale records are removed automatically so the normal remote recovery path can run.
- Preserved the existing HolyBooks source and canonical normalization logic.
- Full test suite: 22 passed, 0 failed, 0 skipped.

PASTOR'S WORKBENCH — DESKTOP UPDATER

The Windows desktop build is configured for signed Tauri updates.

Release flow:
1. Build the signed desktop release with the private Tauri signing key kept OFF the repository.
2. Publish the generated updater artifact and latest.json to the configured release endpoint.
3. Installed Workbench checks the endpoint from Settings > Updates.
4. If a newer signed version exists, Download & Install Update installs it in place.
5. User data in %APPDATA%\Pastors Workbench remains outside the application installer and should survive updates.

Security:
- The public key is safe to ship.
- NEVER commit or upload the private signing key.
- Tauri requires signatures for update installation.

Current endpoint:
https://github.com/XLFatFluffy/Pastor-s-Workbench/releases/latest/download/latest.json

This updater cannot be fully end-to-end tested until a signed release artifact is published.

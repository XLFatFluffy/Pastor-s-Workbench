PHASE 4 CROSS-REFERENCE DATA

Recommended corpus: OpenBible.info cross-reference dataset.
Source: https://www.openbible.info/labs/cross-references/
License: Creative Commons Attribution (CC BY).
Attribution: Cross-reference data courtesy of OpenBible.info.

The Workbench stores the source's verse-pair relationships locally and preserves
source votes when supplied. The source does not provide the Workbench's semantic
types (parallel, quotation, allusion, etc.), so imported records remain "other"
unless a source explicitly supplies a semantic classification.

The application does not invent classifications from the existence of a link.
Personal relationships can be classified by the user.

The current package contains only the previously documented Genesis 1:1 starter
sample. Use the Cross-References workspace to import the full dataset when its
file is available. The importer accepts JSON or TSV.
